Two alternate ways of relating JDC1's plate cells to its beam cells on the selection grid, both dictated by Dave tonight for different songs/moments — a named choice, not a single standing default.

**Look A ("poppy"):** the mirrored-gap sandwich structure actually GS'd into the JDC1 fixture type tonight (Groups 128 "cLD JDC DS ALL," 129 PLATES, 130 BEAM realize it on the rig) — cells alternate plate, beam, plate, beam, so each element type gets its own turn in the fire order. Dave's own word for the resulting feel is "poppy." The underlying mirrored-gap construction is `grid-mirror-symmetry-doctrine`; the GS build mechanics that laid the layout into the fixture type are this run's console-mechanics territory and aren't restated here.

**Look B (for a separate song):** beam instances are paired two-up so each pair matches the width of one plate cell — beams 1+2 ride together, then 3+4, then 5+6, and so on, producing six beam-columns aligned under JDC1's six plate columns. Cells and their paired beams activate at matched widths, so the two element types move together as one wider unit instead of alternating.

Design contrast: Look A trades unified width for alternating rhythm (each type gets its own beat, per `grid-is-a-time-map-doctrine`); Look B trades alternating rhythm for width-matched unity (both types read as one block). Same fixture, same grid, two different time-map decisions — which to use is a per-song call.

History: none — dictated live 2026-07-15; Look A is the layout actually built and GS'd this session, Look B is dictated for a future song, not yet built.
