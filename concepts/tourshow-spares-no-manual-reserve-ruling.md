**CLOSED (Dave, [0722-2cLD]):** the "manual reserve" question is CLOSED. Spares are **physical rig spares**, decided per-venue, and simply **DON'T GET PATCHED**. Programming never accounts for them — no manual-reserve layer exists in the show file. This resolves the SONG_E package's "manual reserve ownership" translation warning permanently.

**Superseded proposal, preserved for history (07-20 bridge, Dave dictated):** a couple of spots were floated to stay OFF the programming entirely ("pictures," Dave's word) — their own group on a SEPARATE executor handle, pointed via saved position presets (the WIZ universals), grabbed/pointed/lit manually when needed, never referenced by any cue. This was framed at the time as "the manual busk/safety layer made concrete in the template rig." **This proposal was never built and is now superseded by the CLOSED ruling above** — do not build it; physical spares handle this need instead, outside the show file entirely.
